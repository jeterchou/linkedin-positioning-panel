# LinkedIn Positioning Panel

[English](README.md) | 繁體中文

**v0.1.1 · 早期測試版**

運用人工智慧協助審查 LinkedIn 個人檔案的 Skill，著重專業定位、有依據的文字修訂，以及個人、團隊與合作成果的清楚歸屬。適用於不同產業與職涯階段。

這是一套以指令運作的 Skill，並非獨立應用程式、LinkedIn 整合服務或真人招募團隊，不預測錄取結果或 LinkedIn 搜尋排名。

## 功能

- **General Audit｜整體審查**：無須指定目標職缺，評估專業身份、資歷訊號、可信的差異化及表達清晰度。
- **Target Role Audit｜目標職務審查**：依提供的職缺描述評估，區分「缺乏證據」與「實際不符合」。
- **七個審查視角**：高階人才招募者、用人主管、企業主管、領域同儕、國際／跨市場讀者、跨部門合作夥伴及第一印象讀者。
- 建立來源清單、欄位涵蓋表、證據台帳、名稱關係與衝突檢查、改善優先順序、保留事實的修改稿及前後複評。
- 區分無法取得的證據與錯誤主張，並在使用者補充證據後更新判斷。
- 環境支援且獲授權時，另以獨立代理對照草稿與提供的來源，最多修正一輪並複查一次；這不等於外部查證。

## 輸入資料

建議先提供 LinkedIn 匯出的 Profile PDF，或直接貼上個人檔案文字。匯出檔未涵蓋的區段可用截圖補充。公開 LinkedIn 網址僅作輔助來源，成功開啟網址不代表已取得完整內容。匯出資料缺少的區段會標示為**未提供**，不推定 LinkedIn 頁面沒有該區段。

不需要，也不會要求密碼、登入 Cookie 或工作階段權杖。Skill 不繞過存取限制，也不會直接發布修改到 LinkedIn。

## 證據與審查原則

個人檔案中的陳述不會自動成為已獨立證實的事實。Skill 分別追蹤履歷自述、使用者確認、外部佐證、推論及未知資訊，並另外記錄查證狀態。整體品牌、獎項、類別、譯名或簡稱不同時，須先釐清關係，才能判定是否矛盾。

只有在環境支援且獲得授權時，才使用獨立代理；否則須明確揭露為七種**模擬視角**。同一模型的多次審查不等於多個獨立證據來源；第一印象審查若已看過完整檔案，也不能稱為盲測。

獨立事實檢查者接收原始資料、所有替代文案與審閱紀錄，不接收作者的自評結論。檢查重點包括時間範圍、個人與團隊歸屬、數據對象、交易類型及意見引用。最多修正一輪並複查一次，剩餘重大問題須明確標示。若無法使用獨立代理，須揭露為自我檢查。另加一位檢查者不代表七種模擬觀點變成獨立審閱，也不代表來源自述獲得外部證實。

不得捏造或擅自提升職稱、雇主、日期、職責、團隊人數、營收、獎項、資格或技能。使用者的職涯期待不能被改寫成已完成的經歷。

### 測試顯示了什麼

在一次測試中，獨立事實檢查者找出改寫草稿與所提供來源不一致的問題，並完成修正後的複查。這次結果顯示該流程曾攔截草稿錯誤，但單次執行無法證明穩定的檢出率或一般可靠性。

對照來源不等於外部查證。PDF 讀取工具與擷取品質會因環境而異，發布前仍須由使用者逐項審閱修改稿。公開文件僅說明流程、測試範圍與限制，不揭露測試者的個人經歷、原文、改寫內容或個別待確認事項。私人輸入與個人報告不隨專案公開。

## 回報與建議

請透過 GitHub Issues 提供使用環境／模型、Skill 版本、輸入格式與涵蓋區段、審查執行方式、預期行為、實際結果，以及最小可重現的虛構或去識別範例。請移除姓名、聯絡資訊、雇主機密與私人職涯規劃。未獲本人授權，不要上傳真實個人檔案或報告。

值得觀察的問題包括：事實是否保留？缺漏區段是否正確處理？不同視角是否帶來有意義的觀察？是否先檢查名稱關係？補充證據後是否修正舊判斷？三份輸出是否完整？
